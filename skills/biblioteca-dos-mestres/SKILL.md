# Biblioteca dos Mestres

Abra o INVENTARIO-DE-RECURSOS.json desta skill instalada usando a localização ou o identificador de recurso fornecido pelo host. Os campos requiredSkills, skillFiles e files listam o que deve estar instalado. Leia os materiais originais em references/produto/ relativo a esta skill. Não procure por eles em Library, Drive, GitHub ou em outro computador. Se esta skill não estiver exposta, peça ao usuário para selecioná-la. Estes são materiais de apoio, não fatos ou provas do usuário. Faça cópias de trabalho dos templates; mantenha os originais intactos. O Guia de Instalação do CopyOS é quem descreve a instalação.

## Como o usuário fala com o CopyOS

O usuário conversa com o CopyOS, não com skills. Esta skill é carregada pela porta de entrada (`copy-de-conversao`) ou diretamente pelo host quando o pedido a aciona; nos dois casos, faça o trabalho sem pedir ao usuário para "usar", "selecionar" ou "chamar" skill nenhuma, e sem citar nomes de skill na resposta: descreva pelo que faz. Quando precisar de outra skill do CopyOS, carregue-a você mesma pela ferramenta de skills do host. Se ela não estiver disponível, diga em uma linha qual arquivo falta instalar e continue com o que dá.
