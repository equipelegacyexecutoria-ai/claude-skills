# Biblioteca dos Mestres - 14 Volumes

Leia `COMO-USAR-ESTA-BIBLIOTECA.md` primeiro: ele diz o que esta biblioteca é (ensino de ofício e
estrutura), o que ela não é (um Banco de Provas), e como ela se posiciona em relação às skills
instaladas.

Comece por `01-navegacao-e-guia-do-usuario.md`. Uma nota sobre numeração: os volumes se
autonumeram internamente como DOC 0-13 (o doc de navegação se chama DOC 0). Os ARQUIVOS são
numerados 01-14, então uma referência interna a "Doc 5" significa o arquivo
`06-estruturas-universais.md`, "Doc 8" significa o arquivo `09-prova-e-credibilidade.md`, e assim
por diante - Doc interno N = arquivo N+1. Os títulos desambiguam tudo.

Exemplos didáticos e estatísticas históricas ao longo do texto são ilustrativos - veja
`AVISO-DE-USO.md` nesta pasta.
