# Construção de visão de mundo e mecanismo

Use na ideação de um mecanismo, de uma grande ideia, de um lote de conceitos de anúncio, de uma premissa de advertorial ou VSL, ou de qualquer coisa próxima de posicionamento. Rode antes de redigir. Faz par com a Regra de Copy de Mecanismo e Autoridade no controlador e com o pensamento de mecanismo de Schwartz na biblioteca.

## 1. "O que precisaria ser verdade?"

Não pergunte "como descrevo este produto como o melhor?". Pergunte:

> **O que precisaria ser verdade sobre o mundo para que este produto fosse a melhor resposta possível?**

Imagine alguém com tempo e dinheiro ilimitados projetando a solução ideal nesta categoria a partir de princípios básicos. Com o que essa pessoa ficaria obcecada? Que visão do problema a levaria, passo a passo, a algo como este produto? Construa essa visão na copy, e o produto vira a conclusão natural dela em vez de uma lista de alegações.

A maioria dos produtos nasceu de conveniência, tendência ou restrição. Conte a história como se tivesse sido projetado a partir de princípios básicos, **usando apenas o que é de fato verdade sobre ele**. A sequência: definir a visão de mundo → derivar o que a resposta ideal precisa ter → mapear isso para os atributos verdadeiros do produto → um atributo que o mapa não sustenta vira uma lacuna honesta ou uma flag, nunca uma invenção.

## 2. As perguntas de construção (em ordem)

1. **O que é mais único aqui** e que os concorrentes não podem dizer? Verifique todas as camadas: o ingrediente ou recurso principal, a combinação, a entrega, a história do fundador ou do fabricante, a origem, a embalagem, o contexto da categoria. Muitas vezes a combinação é a trava, não uma parte isolada.
2. **Como fazemos esses elementos se sustentarem sozinhos:** uma categoria de um só (o mais, o primeiro, o único), onde isso for verdade?
3. **Quais associações fazem esses elementos aterrissar com mais força?** (seção 3)
4. **Por que esta é a resposta certa para este momento:** o que está acontecendo no mercado ou na cultura que a torna oportuna?
5. **Ela trava?** Organize os elementos mais fortes até formarem uma única história em que cada um reforça os outros. Se não travar, reorganize; não force.

## 3. Escolha os fatos verdadeiros com as associações mais ricas

Compradores confiam na forma de uma ideia antes de conferir a ciência dela. A maioria nunca lê o estudo; compra o raciocínio. Então, entre os seus fatos VERDADEIROS, lidere com os que carregam as associações existentes mais fortes, e formule cada um na sua forma verdadeira mais vívida.

- Um exemplo fictício: "carvalho recuperado de um celeiro dos anos 1920" e "madeira velha" podem descrever a mesma mesa. Ambos são verdade; o primeiro carrega idade, ofício e uma história antes de qualquer prova ser oferecida.
- Um teste rápido de associação: liste nomes, origens ou enquadramentos candidatos e peça a algumas pessoas que os ordenem no instinto, sem critério. A ordem mostra o que cada palavra já significa para os compradores. Use para nomes de mecanismo, linhas de origem, destaques de ingrediente e substantivos de gancho.
- Um nome de mecanismo funciona melhor quando montado a partir das partes verdadeiras de maior associação.

Uma alegação causal ou científica explícita dentro de uma história movida a associação é a forma que mais merece uma flag, porque o custo dela chega depois.

## 4. Psicologia primeiro, depois os fatos

As pessoas travam encarando a ficha técnica, esperando que uma ideia apareça. Inverta: decida primeiro o efeito que você quer que o leitor sinta, depois construa o caso honesto mais forte para ele.

- **Ideie com força total.** Empurre a visão de mundo, o enquadramento de categoria de um só e as associações. Mecanismos candidatos, origens e alegações maiores são permitidos num rascunho; rotule todo elemento que você inventou ou não conseguiu confirmar, para que o usuário veja de relance o que é real. Afie livremente; nunca higienize um rascunho para ele parecer seguro.
- **Depois faça-o se sustentar,** para cada elemento rotulado, com o primeiro destes que funcionar:
  1. **Verifique:** a pesquisa confirma.
  2. **Torne verdade:** mude o produto, a oferta, o fornecimento ou a prova para que a alegação vire um fato. Muitas vezes é a jogada de maior alavancagem: se uma origem é a melhor história, pergunte se o negócio consegue de fato obtê-la.
  3. **Delimite** ao que é sustentável, mantendo a pressão.
  4. **Torne claramente figurativo** em vez de uma alegação factual.
  5. **Substitua** pela alternativa verdadeira mais forte.
  6. **Corte** só quando nada acima funcionar.

O usuário decide quais elementos rotulados são publicados. O rótulo é o que torna essa decisão informada: nada inventado sai parecendo um fato.
