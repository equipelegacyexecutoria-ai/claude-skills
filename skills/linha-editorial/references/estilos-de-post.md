# Catálogo de estilos de post

Cada estilo tem objetivo e etapa do funil (D = descoberta, C = consideração, V = decisão/venda,
F = fidelização). Ao montar a linha editorial, escolher **6 a 10 estilos** que caibam na marca e no time,
escrever a estrutura de cada um adaptada ao segmento e dar um exemplo real.

## Reels / TikTok / Shorts (alcance e conexão)

| Estilo | Funil | Estrutura curta |
|---|---|---|
| Mito ou verdade | D | Afirmação comum → "mito" → por quê, com 1 fato → o que fazer → CTA salvar/enviar |
| Erro comum | D/C | "Se você faz X, está perdendo Y" → mostra o erro → o certo → resultado |
| Passo a passo / tutorial | C | Promessa do resultado → 3 a 5 passos rápidos → resultado na tela |
| Lista rápida | D | "3 sinais de que..." → itens com corte seco → CTA |
| Resposta a pergunta/comentário | C | Print da pergunta → resposta direta → convite para perguntar mais |
| Bastidor / um dia na empresa | C/F | O que ninguém vê → processo → pessoas → orgulho do trabalho |
| Antes e depois | C/V | Antes → o que foi feito → depois → como conseguir |
| Caso / depoimento | V | Situação do cliente → o problema → o que mudou com número → CTA |
| POV / situação do dia a dia | D | Cena que o público vive → reação → identificação → marca entra leve |
| Opinião do especialista | D/C | Posição clara sobre algo do setor → argumento → "concorda?" |
| Notícia do setor explicada | D | Fato recente → o que muda para você → o que fazer |
| Trend adaptada | D | Só quando cabe na marca; áudio/formato da trend com o assunto do negócio |
| Entrevista / rua / pergunta ao time | D | Pergunta simples → respostas → conclusão |
| Oferta / chamada | V | Dor → solução → prova → condição e prazo → CTA direto |

Regras: gancho nos 2 primeiros segundos (fala + texto na tela), legenda queimada, conteúdo original
(nunca repostar vídeo com marca d'água de outra rede), 15 a 60 s para alcance, até 90 s para conteúdo
denso. Medir retenção e envios por alcance.

## Carrossel (salvamento, confiança, autoridade)

| Estilo | Funil | Estrutura curta |
|---|---|---|
| Guia / checklist | C | Capa com promessa → 1 item por card → resumo → CTA salvar |
| Passo a passo | C | Capa → passos numerados → erro a evitar → CTA |
| Comparativo (isso x aquilo) | C/V | Capa com dilema → critérios lado a lado → veredito |
| Caso com números | V | Capa com resultado → situação → o que foi feito → número → lição |
| Dados / pesquisa | D/C | Dado surpreendente → contexto → o que significa → fonte |
| "Pare de fazer X" | D | Capa provocativa → por que é erro → o que fazer no lugar |
| Estilo post do X (Twitter) | D | Texto em formato de post, card a card, opinião forte |
| Narrativa / história | C/F | Começo com tensão → virada → aprendizado |
| Perguntas frequentes | V | Uma objeção por card, resposta curta → CTA |
| Oferta detalhada | V | O que é → para quem → o que inclui → condição → como comprar |

Regras: capa decide tudo (manchete curta, promessa clara); 5 a 10 cards; último card com CTA; texto grande
legível no celular.

## Estático (imagem única)

Frase/manifesto da marca (F), anúncio de novidade (V), print de depoimento (V), data comemorativa (F),
meme do segmento (D), aviso/serviço (F). Usar pouco: tem o menor engajamento médio.

## Stories (relacionamento e venda diária)

Rotina sugerida para dia útil (3 a 5 telas):
- **Manhã**: bastidor ou "bom dia" com algo real do dia (equipe, produção, agenda).
- **Meio do dia**: interação (enquete, quiz, caixinha de perguntas, "isso ou aquilo").
- **Noite**: divulgar o post do feed do dia (com figurinha de link) ou sequência de venda.

Sequência de venda em stories (3 a 7 telas): gancho → contexto/dor → virada/solução → prova → oferta → CTA
(link ou "responde QUERO").
Uma vez por semana: caixinha de perguntas, e as respostas viram Reels/carrossel.
Destaques fixos: Comece aqui, Serviços/Produtos, Depoimentos, Dúvidas, Bastidores.

## Outros formatos

- **Live / colab**: parceria com perfil complementar, 1 por mês; vira cortes depois.
- **LinkedIn**: texto nativo contando história com aprendizado; documento PDF (carrossel); enquete;
  perfil do dono rende mais que a página da empresa.
- **YouTube longo**: aula/caso aprofundado; cortes viram Shorts e Reels.
- **WhatsApp (canal/lista)**: novidade, oferta, conteúdo da semana resumido.

## Quadros fixos (séries)

Dê nome e dia para 1 a 3 estilos que mais combinam com a marca. Exemplos: "Terça do Mito", "Caso da
Semana" (quinta), "Pergunta do Seguidor" (segunda). Quadro cria hábito e facilita a produção em lote.

## CTA: variar

Salvar ("salva para usar depois"), enviar ("manda para quem precisa ver"), comentar (pergunta específica,
não "o que acharam?"), seguir, link na bio, direct com palavra-chave, WhatsApp, visitar a loja.
No máximo 20% a 30% dos posts com CTA de compra.
