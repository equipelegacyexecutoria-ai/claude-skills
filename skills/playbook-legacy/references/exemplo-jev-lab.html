O que é o JEV Lab

O JEV Lab é um programa da Legacy que roda no seu computador e usa inteligência artificial para estudar conteúdo de redes sociais. No menu à esquerda ficam as ferramentas:

a mais usada

Extrator de perfil

Você informa um ou vários perfis do Instagram e um período. O JEV puxa todos os posts com as métricas, a fala de cada vídeo e o texto de cada card dos carrosséis. Tudo sai em planilha, documento do Word e pastas com as imagens.

tendências

Radar de vídeos

Mostra o que está em alta agora num nicho e num país: anúncios e vídeos do TikTok, Reels e anúncios da Meta. A IA explica por que os primeiros colocados estão funcionando.

referência

Como funciona e Playground

Como funciona explica o Radar. O Playground é uma área técnica para testar a IA: você não precisa dela no dia a dia.

Onde ele roda

O JEV Lab funciona no próprio computador, pelo endereço localhost:3777 no navegador. Ele só fica no ar enquanto a janela preta (o terminal) estiver aberta. Isso é explicado no Passo 1.

checklist

Antes de começar

Confira se você tem tudo isto. Pode ir marcando:

  • Um computador com a pasta do projeto. Neste computador ela fica em Área de Trabalho → PROJETOS ANTIGRAVIDADE → JARVIS EXTRATOR DE PERFIS.
  • O Google Chrome instalado.
  • O Node.js instalado (é o que faz o programa rodar).
  • A senha de acesso do JEV Lab. Peça a quem cuida do JEV.
  • Uma conta secundária do Instagram, nunca a conta principal da empresa (o motivo está no Passo 3).
  • Créditos no OpenRouter, o serviço de IA. Só são gastos quando a IA transcreve vídeos ou lê textos. Veja Quanto custa.
Neste computador já está tudo pronto

O Node.js, o Chrome e o ffmpeg (usado nos vídeos longos) já estão instalados, e uma conta do Instagram já está conectada. Se for usar aqui, pode ir direto para o Passo 1.

Vou instalar num computador novo. O que eu faço?
  1. Instale o Google Chrome.
  2. Baixe o Node.js em nodejs.org (botão da versão LTS) e instale clicando em "Avançar" até o fim.
  3. Copie a pasta do projeto para o computador. Ela precisa ter o arquivo .env, que guarda a chave de IA e a senha: peça a quem cuida do JEV.
  4. Abra a janela preta dentro da pasta (veja o Passo 1) e rode uma vez só:
npm install

Opcional, para transcrever vídeos com mais de ~2,5 minutos: instale o ffmpeg com o comando abaixo e feche e abra a janela preta de novo.

winget install Gyan.FFmpeg
passo 1

Ligar o programa

O JEV Lab liga por uma janela de comandos (a "janela preta"). Escolha um dos dois jeitos abaixo.

Jeito A: pelo VS Code (o programa azul de código)

  1. Abra o VS Code.
  2. Abra a pasta do projeto. Menu File → Open Folder (Arquivo → Abrir pasta) e escolha JARVIS EXTRATOR DE PERFIS. Se ela já aparece aberta à esquerda, pule este passo.
  3. Abra o terminal. Menu Terminal → New Terminal (Novo terminal). Uma área de texto abre na parte de baixo.
  4. Digite o comando e aperte Enter:
    npm start
  5. Espere a mensagem de pronto. Quando aparecer JEV Lab rodando em http://localhost:3777, o programa está ligado.

Jeito B: sem o VS Code

  1. Abra a pasta JARVIS EXTRATOR DE PERFIS. Use o Explorador de Arquivos (o ícone de pasta amarela).
  2. Clique na barra de endereço. É a barra lá em cima, onde aparece o caminho da pasta. Apague o que estiver escrito, digite cmd e aperte Enter: abre uma janela preta já dentro da pasta.
  3. Digite npm start e aperte Enter. Espere a mensagem JEV Lab rodando em http://localhost:3777.
Não feche a janela preta

Enquanto você usa o JEV, ela precisa ficar aberta (pode minimizar). Se ela fechar, o programa desliga. Para desligar de propósito, clique nela e aperte Ctrl + C.

Use npm start, não npm run dev

O npm run dev é o modo de quem mexe no código: ele reinicia o programa sempre que um arquivo do projeto é salvo, e isso interrompe uma extração no meio. Para o dia a dia, use sempre npm start.

passo 2

Abrir e entrar

  1. Abra o Google Chrome.
  2. Digite localhost:3777 e aperte Enter. Use a barra de endereço, lá em cima.
  3. Digite a senha de acesso e clique em Entrar.
  4. Na primeira vez abre um vídeo tutorial de 1 minuto. Pode assistir ou fechar: dá para rever depois no menu, em Tutorial em vídeo.
Deixe nos favoritos

Salve localhost:3777 nos favoritos do Chrome (Ctrl + D). Para sair do app, use Sair, no pé do menu à esquerda.

passo 3 · só na primeira vez

Conectar o Instagram

O JEV lê o Instagram como uma pessoa faria: abre o perfil num Chrome próprio, já logado numa conta. Essa conta precisa ser conectada uma vez.

  1. Clique em Extrator de perfil. Fica no menu à esquerda.
  2. Olhe o quadro "Instagram", no topo da tela. Se estiver escrito conectado em verde, pule para o Passo 4.
  3. Se não estiver, clique em CONECTAR. Uma janela do Chrome abre sozinha, já na página de login do Instagram.
  4. Entre com a conta secundária. Digite usuário e senha. Se o Instagram pedir um código de verificação, digite na mesma janela.
  5. Espere a janela fechar sozinha. Isso acontece quando o login é detectado (você tem até 6 minutos). O quadro passa a mostrar conectado.
Use uma conta secundária

Automação vai contra as regras do Instagram e pode levar a bloqueios. Nunca conecte a conta principal da empresa ou de um cliente. O JEV não curte, não comenta e não segue ninguém: ele só lê.

Trocar ou desconectar a conta

O login fica salvo só neste computador. Ainda não existe botão para desconectar: para trocar de conta, peça a quem cuida do JEV.

passo 4

Preencher o pedido

Na tela do Extrator de perfil, preencha o formulário de cima para baixo.

  1. PERFIS. Digite o @ do perfil, por exemplo @clailtonluiz. Para vários de uma vez, separe por vírgula: @clailtonluiz, @legacyexecutoria. Também pode colar o link do perfil (instagram.com/perfil). O limite é de 20 perfis por vez.
  2. DE e ATÉ. O período, pela data em que os posts foram publicados. Clique no campo e escolha no calendário.
  3. LIMITE DE POSTS (por perfil). O máximo de posts de cada perfil (o padrão é 100). Se o período tiver mais, ficam os mais recentes e a tela avisa.
  4. TODAS DO PERÍODO. Marque para pegar tudo do período, sem limite. Em períodos longos (vários meses) pode demorar alguns minutos.
  5. TIPO DE POST. Escolha um: TODOS, REELS (Reels e vídeos do feed), CARROSSÉIS ou FOTOS.
  6. TRANSCREVER VÍDEOS E CARROSSÉIS. Ligado, a IA escreve palavra por palavra a fala de cada vídeo e lê o texto escrito em cada card dos carrosséis. Gasta créditos. Desligado, sai todo o resto (métricas, legendas, links e imagens) e o custo é zero.

passo 5

Iniciar e acompanhar

  1. Clique em INICIAR.
  2. Uma janela do Chrome abre sozinha. Ela rola o perfil: é o JEV trabalhando. Não mexa nela e não feche; ela fecha sozinha no fim.
  3. Acompanhe o quadro ANDAMENTO. Cada linha é uma etapa: perfil lido, quantos seguidores, carrosséis encontrados, avisos. As linhas mais novas aparecem em cima. Linhas em vermelho são alertas; as outras são informação.
  4. Veja os números no topo. Posts no período, vídeos, transcritos, views somadas, tempo e custo (US$), o gasto real de IA desta extração.
  5. Terminou quando aparece "concluído" no ANDAMENTO. Na mesma linha vem o resumo do que foi feito.
Precisa parar no meio?

Clique em PARAR. O que já foi coletado continua na tela e pode ser exportado normalmente.

passo 6

Ler os resultados

A tabela embaixo tem uma linha por post. Com vários perfis, o @ aparece embaixo da data.

  1. Clique numa linha para abrir os detalhes. Aparecem a legenda completa, a transcrição (ou a copy de cada card) e as observações daquele post.
  2. Clique em abrir ↗ para ver o post no Instagram.
  3. Clique de novo na linha para fechar os detalhes.

Posts em collab (feitos por dois perfis juntos)

Um post em collab aparece no perfil de todos os autores, mas o JEV coloca ele só no perfil de quem postou, para não duplicar. No outro perfil, o ANDAMENTO avisa, por exemplo: "3 collabs postados por @clailtonluiz ficaram de fora". Para ter esses posts, inclua também o @ de quem postou.

Salvamentos e compartilhamentos dos perfis da Legacy

Esses números só existem para o dono da conta. O JEV consegue buscá-los pela API oficial do Instagram, mas isso exige um "token" de cada perfil próprio configurado por quem cuida do JEV. Sem o token, as colunas ficam vazias.

Exporte as imagens no mesmo dia

Os links das imagens que o Instagram entrega expiram depois de um tempo. Se um .zip vier com imagens faltando, rode a extração de novo e exporte em seguida. O arquivo LEIA-ME.txt dentro do .zip avisa quando faltou algo.

Ligar números e imagens

Cada carrossel tem uma pasta com nome fixo, que aparece igual na planilha, no documento e nos .zip. Assim você sabe exatamente de qual design são aquelas curtidas.

instagram-2-perfis-2026-09-20_2026-09-27-carrosseis-imagens.zip
├─ LEIA-ME.txt                      ← explica a organização
└─ carrosseis/
   ├─ clailtonluiz/                   ← uma pasta por perfil
   │  └─ 2026-09-26 - Ddw81HtHyJD/     ← data + código do post
   │     ├─ card-01.jpg              ← cada card em tamanho original
   │     ├─ card-02.jpg … card-11.jpg
   │     └─ copy.txt                 ← link, métricas, legenda e copy
   └─ legacyexecutoria/
      └─ 2026-09-25 - Ddt6d9okWPe/ …
  1. Na planilha. A coluna pasta_imagens mostra o caminho exato da pasta daquele carrossel (ex.: carrosseis/clailtonluiz/2026-09-26 - Ddw81HtHyJD).
  2. No documento do Word. Cada carrossel tem a linha "Pasta das imagens" e, no começo, um índice com todas as pastas. Cada imagem vem com o nome do arquivo (ex.: "Card 3 · card-03.jpg").
  3. No .zip. Abra a pasta com esse nome: estão lá as imagens de todos os cards e o copy.txt com os números.
outra ferramenta

Radar de vídeos

O Radar ("em alta agora") busca o que está viralizando e performando num nicho e num país. Depois, a IA assiste os primeiros colocados e explica o que eles têm em comum: gancho, formato, primeiro segundo e emoção.

  1. Clique em Radar de vídeos, no menu.
  2. Confira as contas, no topo. O TikTok orgânico precisa da conta do TikTok e os Reels precisam da conta do Instagram (use CONECTAR, como no Passo 3). Os anúncios do TikTok e da Meta funcionam sem login; conectar o TikTok Ads mostra mais anúncios por nicho. O botão IMPORTAR só é usado na versão online.
  3. Preencha o pedido. Em NICHO / TERMO, escreva o assunto, por exemplo "curso de inglês" (obrigatório para anúncios da Meta). Depois escolha o PAÍS, o PERÍODO (7 ou 30 dias) e POR PLATAFORMA (quantos resultados de cada, padrão 20).
  4. Escolha as plataformas. Clique nos quatro quadros para ligar ou desligar (os escuros estão ligados): TikTok anúncios, TikTok orgânico, Instagram Reels e Anúncios Meta.
  5. Escolha quantos vídeos a IA vai explicar. Em EXPLICAR OS TOP: 3, 5 ou 10 de cada plataforma. Mais vídeos = mais tempo e mais custo.
  6. Clique em INICIAR. O navegador trabalhando aparece ao vivo no painel.
  7. Leia os resultados. "Por que está funcionando", "virais agora", "estilos que mais performam", "copies que funcionam" e "palavras-chave da categoria". O botão CSV baixa a lista e TELA CHEIA serve para apresentar.
O que não existe publicamente

Cliques, CTR, vendas, gasto e público de anúncios de terceiros não são divulgados pela Meta nem pelo TikTok. O Radar usa sinais indiretos: dias no ar, número de versões, posição por impressões, índice de CTR do Creative Center e views e curtidas do orgânico.

Quanto custa

O JEV só gasta créditos quando a inteligência artificial trabalha. Esses créditos ficam no OpenRouter, o serviço que dá acesso à IA. Abrir o programa, ler perfis e exportar arquivos não custa nada.

Três jeitos de economizar
  • Antes de uma extração grande, faça um teste pequeno (limite 5, uma semana).
  • Se você só precisa dos números, desmarque "transcrever".
  • Escolha o tipo de post certo: só carrosséis, por exemplo, não transcreve os vídeos à toa.
jeito certo

Boas práticas

Conta secundária

Conecte sempre uma conta secundária do Instagram, nunca a da empresa ou a de um cliente.

npm start

Ligue o programa com npm start e não feche a janela preta nem a aba do Chrome durante uma extração.

Uma coisa por vez

O Chrome do JEV faz uma tarefa de cada vez. Espere uma extração terminar antes de começar outra ou de conectar uma conta.

Divida os pedidos grandes

Para muitos perfis grandes ou períodos de vários meses, divida em partes. É mais rápido de conferir e menos chamativo para o Instagram.

Guarde os arquivos

Mova os arquivos exportados da pasta Downloads para a pasta do cliente ou do projeto.

Senha é segredo

Não compartilhe a senha do app nem o arquivo .env: eles dão acesso aos créditos de IA.

socorro

Problemas comuns e como resolver

Clique na pergunta para ver a resposta.

Digitei localhost:3777 e a página não abre

O programa está desligado. Faça o Passo 1 (npm start), espere a mensagem "JEV Lab rodando" e recarregue a página com F5. A janela preta precisa continuar aberta.

Apareceu "npm ERR! enoent … package.json"

A janela preta foi aberta na pasta errada. Feche, abra a pasta JARVIS EXTRATOR DE PERFIS e abra a janela preta de dentro dela (Passo 1, jeito B). Se a pasta tiver só um arquivo .zip, extraia o .zip primeiro.

"npm" não é reconhecido como um comando

O Node.js não está instalado. Instale a versão LTS em nodejs.org, feche e abra a janela preta de novo.

A tela diz que o Instagram não está conectado

Faça o Passo 3. Se a conta foi desconectada pelo Instagram (acontece de vez em quando), é só conectar de novo.

Aviso de que o navegador "está em uso"

Outra extração ou uma conexão de conta está rodando no Chrome do JEV. Espere terminar, ou clique em PARAR na outra tarefa, e tente de novo.

O Instagram pediu verificação, código ou captcha

Resolva na janela do Chrome que o JEV abriu (digite o código ou marque o captcha). A extração continua sozinha depois disso.

O perfil é privado

Perfil privado só pode ser lido se a conta conectada seguir esse perfil. Nos outros casos, o JEV pula o perfil com um aviso e continua com os demais.

As curtidas vieram em branco

O autor escondeu as curtidas do post, e o Instagram não mostra o número para ninguém além do dono. A observação do post diz "o autor oculta as curtidas". Não é erro.

Os carrosséis e as fotos não têm views

O Instagram não mostra publicamente views de carrosséis e fotos, só de Reels e vídeos. Para carrosséis, use curtidas, comentários e reposts.

Faltou um post que eu sei que está no perfil

Veja no ANDAMENTO se há um aviso de "collabs postados por @… ficaram de fora". Post em collab entra só no perfil de quem postou: inclua esse @ na lista de perfis. Confira também o período, que conta pela data de publicação, e o tipo de post escolhido.

A extração parou no meio ou a página recarregou sozinha

Se o programa foi ligado com npm run dev, salvar qualquer arquivo do projeto reinicia o servidor: use npm start. Se o Instagram limitou a coleta, o ANDAMENTO mostra um aviso em vermelho; espere um pouco e tente de novo.

A transcrição falhou para todos os posts

Provavelmente os créditos do OpenRouter acabaram (a tela avisa). Peça a recarga. Enquanto isso, dá para extrair com "transcrever" desmarcado.

Um vídeo longo não foi transcrito

Vídeos com mais de ~2,5 minutos precisam do ffmpeg para ser comprimidos. Neste computador ele já está instalado; em outro, veja o quadro "computador novo" em Antes de começar.

Não acho os arquivos que exportei

Estão na pasta Downloads do Windows (no Chrome, Ctrl + J mostra os downloads). O nome começa com instagram-.

O .zip veio com imagens faltando

Os links das imagens do Instagram expiram. Rode a extração de novo e exporte logo em seguida. O LEIA-ME.txt do .zip diz quantos arquivos faltaram.

Glossário

Reel
Vídeo curto e vertical do Instagram.
Carrossel
Post com várias imagens ou vídeos que a pessoa passa para o lado.
Card (ou slide)
Cada imagem de um carrossel.
Copy
O texto do conteúdo: a fala do vídeo ou o que está escrito nos cards.
Legenda
O texto escrito embaixo do post.
Transcrição
A fala de um vídeo escrita palavra por palavra pela IA.
Collab
Post feito em parceria, que aparece no perfil de dois ou mais autores.
Views
Quantas vezes um vídeo foi reproduzido.
Reposts
Quantas pessoas repostaram o post no próprio perfil.
CSV
Arquivo de planilha que abre no Excel ou no Google Planilhas.
DOCX
Documento do Word (abre também no Google Docs).
ZIP
Pasta compactada: clique com o botão direito → Extrair tudo.

OpenRouter
